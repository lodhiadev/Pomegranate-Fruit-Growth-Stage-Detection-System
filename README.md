# Pomegranate Growth Stage Detection (YOLOv8)

Single YOLOv8 model to detect pomegranate fruits and classify growth stages.

## Train

python train.py

## Validate

python val.py

## Inference

python infer.py

## Export

python export.py

## Environment (Verified)

- Python: 3.13.9
- Ultralytics: 8.3.228
- PyTorch: 2.9.1
- Hardware tested: Apple Silicon (MPS)

These versions were used to obtain the reported accuracy.
